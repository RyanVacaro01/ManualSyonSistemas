# Producao

O modulo de Producao gerencia todo o processo produtivo, desde o planejamento ate o controle de qualidade.

## Funcionalidades

### Planejamento de Producao

Para criar uma ordem de producao:

1. Acesse **Producao** > **Nova Ordem**
2. Selecione o produto a ser produzido
3. Informe a quantidade
4. Defina a data prevista de conclusao
5. Confirme a ordem de producao

### Controle de Producao

Acompanhe a producao em tempo real:

- **Fila de Producao**: Ordens aguardando inicio
- **Em Producao**: Ordens em andamento
- **Concluido**: Ordens finalizadas
- **Parado**: Ordens com problemas

### Roteiro de Producao

Configure os processos de fabricacao:

| Etapa | Descricao | Tempo Estimado |
|-------|-----------|----------------|
| Corte | Corte da materia prima | 2 horas |
| Costura | Costura das pecas | 3 horas |
| Acabamento | Acabamento final | 1 hora |
| Controle Qualidade | Inspecao final | 0.5 horas |

### Controle de Qualidade

Registre os resultados da inspecao:

1. Selecione a ordem de producao
2. Registre as amostras inspecionadas
3. Informe aprovado/reprovado
4. Adicione observacoes

---

## Dicas

!!! tip "Dica"
    Use o planejamento de producao para evitar gargalos e otimizar o uso dos recursos.

!!! warning "Atencao"
    Ordens de producao com problemas de qualidade devem ser bloqueadas ate a correcao do defeito.
