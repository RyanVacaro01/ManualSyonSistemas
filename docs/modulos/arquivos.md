# Arquivos

O modulo de Arquivos gerencia documentos e anexos do sistema.

## Funcionalidades

### Upload de Arquivos

Para enviar um arquivo:

1. Acesse **Arquivos** > **Novo Arquivo**
2. Selecione o arquivo do computador
3. Adicione informacoes:
    - Titulo
    - Descricao
    - Categoria
    - Tags
4. Clique em **Enviar**

### Categorias de Arquivos

Organize seus documentos por categorias:

| Categoria | Descricao | Exemplos |
|-----------|-----------|----------|
| Fiscal | Documentos fiscais | NF-e, CT-e, NFS-e |
| Contratos | Documentos juridicos | Contratos, aditivos |
| Comercial | Materiais de vendas | Catalogos, precos |
| RH | Documentos de pessoal | Holerites, certidoes |
| Sistema | Arquivos do sistema | Backups, configuracoes |

### Compartilhamento

Compartilhe arquivos com a equipe:

1. Selecione o arquivo
2. Clique em **Compartilhar**
3. Defina as permissoes:
    - Visualizar apenas
    - Visualizar e baixar
    - Editar
4. Envie o link por email ou mensagem

### Controle de Versoes

O sistema mantem historico de versoes:

- Todas as alteracoes sao registradas
- Possibilidade de reverter versoes anteriores
- Comparacao entre versoes

---

## Dicas

!!! tip "Dica"
    Use tags para facilitar a busca por arquivos especificos.

!!! warning "Atencao"
    Documentos fiscais devem ser mantidos por no minimo 5 anos conforme legislacao vigente.
