# Clientes

O modulo de Clientes permite o cadastro e gestao completa dos clientes e parceiros comerciais.

## Funcionalidades

### Cadastro de Clientes

Para cadastrar um novo cliente:

1. Acesse o menu **Clientes** na barra lateral
2. Clique em **Novo Cliente**
3. Preencha os dados:
    - **Razao Social**: Nome completo da empresa
    - **Nome Fantasia**: Nome comercial
    - **CNPJ/CPF**: Documento fiscal
    - **Inscricao Estadual**: IE do cliente
4. Adicione os dados de contato:
    - Endereco completo
    - Telefones
    - Email
5. Configure as condicoes comerciais
6. Clique em **Salvar**

### Tipos de Cliente

| Tipo | Descricao | Caracteristicas |
|------|-----------|-----------------|
| Revendedor | Clientes que revendem nossos produtos | Tabela de precos especial |
| Consumidor Final | Clientes pessoa fisica | NF-e para consumidor |
| Distribuidor | Parceiros de distribuicao | Condicoes especiais |
| Exportacao | Clientes internacionais | Documentacao especial |

### Historico de Compras

O sistema mantem um historico completo de todas as compras do cliente:

- Pedidos realizados
- Notas fiscais emitidas
- Titulos a receber
- Devolucoes

### Gestao de Creditos

Verifique o limite de credito do cliente:

1. Acesse **Clientes** > **Consulta**
2. Selecione o cliente
3. Clique em **Limite de Credito**

---

## Dicas

!!! tip "Dica"
    Mantenha os dados de contato sempre atualizados para garantir a comunicacao eficiente com seus clientes.

!!! info "Informacao"
    O sistema verifica automaticamente o limite de credito antes de confirmar novos pedidos.
