# Pessoas

O modulo de Pessoas gerencia o cadastro de funcionarios, vendedores e equipes.

## Funcionalidades

### Cadastro de Funcionarios

Para cadastrar um funcionario:

1. Acesse **Pessoas** > **Novo Funcionario**
2. Preencha os dados pessoais:
    - Nome completo
    - CPF/RG
    - Data de nascimento
    - Estado civil
3. Informe os dados profissionais:
    - Cargo
    - Departamento
    - Data de admissao
    - Salario
4. Adicione dados bancarios para pagamento
5. Clique em **Salvar**

### Vendedores

Cadastre e gerencie a equipe de vendas:

| Campo | Descricao |
|-------|-----------|
| Codigo | Codigo do vendedor |
| Nome | Nome completo |
| Meta Mensal | Meta de vendas |
| Comissao | Percentual de comissao |
| Regiao | Area de atuacao |

### Controle de Ponto

Registre a jornada de trabalho:

1. Acesse **Pessoas** > **Ponto**
2. Selecione o funcionario
3. Registre entrada e saida
4. Visualize osaldo de horas

### Relatorios de RH

- **Lista de Funcionarios**: Cadastro completo
- **Folha de Pagamento**: Resumo mensal
- **Pontos Pendentes**: Funcionarios com pendencias
- **Aniversariantes**: Lista de aniversariantes do mes

---

## Dicas

!!! tip "Dica"
    Mantenha os dados dos funcionarios sempre atualizados para garantir o correto processamento da folha de pagamento.

!!! info "Informacao"
    O sistema envia automaticamente lembretes para aniversariantes dos funcionarios.
