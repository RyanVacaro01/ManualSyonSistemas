# Marketplace

O modulo de Marketplace integra os canais de vendas online com o sistema ERP.

## Funcionalidades

### Integracao com Marketplaces

Conecte os principais canais de venda online:

| Marketplace | Status | Sincronizacao |
|-------------|--------| Instantanea |
| Mercado Livre | ✅ Ativo | A cada 15 min |
| Amazon | ✅ Ativo | A cada 15 min |
| Magalu | ✅ Ativo | A cada 15 min |
| Americanas | ✅ Ativo | A cada 15 min |
| Shopee | ✅ Ativo | A cada 15 min |

### Configuracao das Integracoes

Para configurar uma integracao:

1. Acesse **Marketplace** > **Configuracoes**
2. Selecione o canal desejado
3. Informe as credenciais de acesso
4. Configure os paramentros de sincronizacao
5. Ative a integracao

### Sincronizacao de Produtos

O sistema sincroniza automaticamente:

- Cadastro de produtos
- Precos e estoques
- Pedidos recebidos
- Status de envio

### Gestao de Pedidos Online

Gerencie pedidos de todos os canais em um so lugar:

1. Acesse **Marketplace** > **Pedidos**
2. Visualize pedidos consolidados
3. Processe normalmente pelo modulo de Pedidos
4. Atualize status de envio

---

## Dicas

!!! tip "Dica"
    Configure alertas de estoque baixo para evitar vendas sem estoque disponivel nos marketplaces.

!!! warning "Atencao"
    Verifique periodicamente se a sincronizacao esta funcionando corretamente para evitar divergencias de estoque.
