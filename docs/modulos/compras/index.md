# Compras

O modulo de Compras gerencia todo o processo de aquisicao de materiais e servicos.

## Funcionalidades

### Solicitacao de Compra

Para criar uma solicitacao de compra:

1. Acesse **Compras** > **Nova Solicitacao**
2. Selecione o fornecedor
3. Adicione os itens desejados
4. Informe a quantidade e prazo
5. Envie para aprovacao

### Pedidos de Compra

Apos a aprovacao, gere o pedido de compra:

1. Acesse **Compras** > **Pedidos**
2. Selecione a solicitacao aprovada
3. Confirme os itens e quantidades
4. Envie ao fornecedor

### Controle de Fornecedores

Mantenha um cadastro atualizado de fornecedores:

| Campo | Descricao |
|-------|-----------|
| Razao Social | Nome da empresa |
| CNPJ | Documento fiscal |
| Contato | Nome do responsavel |
| Telefone | Numero de contato |
| Email | Endereco eletronico |
| Condicao Pagamento | Prazo de pagamento |

### Notas Fiscais de Entrada

Registre as notas fiscais de compra:

1. Acesse **Recebimento** > **Notas Fiscais**
2. Selecione o pedido de compra
3. Confirme os itens recebidos
4. Registre divergencias se houver

---

## Dicas

!!! tip "Dica"
    Mantenha o historico de compras atualizado para negociar melhores condicoes com fornecedores.

!!! warning "Atencao"
    Compras nao autorizadas nao geram pedido de compra. Certifique-se de que a solicitacao foi aprovada.
