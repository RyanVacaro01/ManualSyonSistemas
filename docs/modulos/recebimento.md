# Recebimento

O modulo de Recebimento gerencia a entrada de mercadorias e materias primas no estoque.

## Funcionalidades

### Recebimento de Mercadorias

Para registrar o recebimento de uma nota fiscal:

1. Acesse **Recebimento** > **Nova Entrada**
2. Informe o numero da nota fiscal
3. Selecione o fornecedor
4. Confirme os itens recebidos
5. Registre quantidades e condicoes

### Conferencia Fisica

Realize a conferencia dos itens recebidos:

1. Acesse **Recebimento** > **Conferencia**
2. Selecione a nota fiscal
3. Confira cada item:
    - Quantidade conferida
    - Condicao do produto
    - Divergencias encontradas
4. Registre o resultado da conferencia

### Controle de Devolucoes

Registre devolucoes de mercadorias:

| Motivo | Descricao |
|--------|-----------|
| Defeito | Produto com defeito de fabricacao |
| Divergencia | Quantidade ou item divergente |
| Vencimento | Produto vencido |
| Retorno | Devolucao do cliente |

### Relatorios

- **Entradas do Dia**: Notas fiscais recebidas
- **Conferencias Pendentes**: Notas aguardando conferencia
- **Devolucoes Realizadas**: Historico de devolucoes

---

## Dicas

!!! tip "Dica"
    Realize a conferencia fisica de todas as entradas para evitar divergencias de estoque.

!!! warning "Atencao"
    Mercadorias com avarias devem ser registradas imediatamente para acionar o seguro ou devolucao ao fornecedor.
